## Special Thanks

### Inspiration & Resources

This project was made possible thanks to:

- **Cuckoo Sandbox** - Automated malware analysis platform
  - https://cuckoosandbox.org

- **FLARE VM** - Windows-based security distribution by Mandiant
  - https://github.com/mandiant/flare-vm

- **REMnux** - Linux toolkit for malware analysis by Lenny Zeltser
  - https://remnux.org

- **Ghidra** - NSA's software reverse engineering framework
  - https://ghidra-sre.org

- **YARA** - Pattern matching tool for malware researchers
  - https://virustotal.github.io/yara/

- **MITRE ATT&CK** - Knowledge base of adversary tactics and techniques
  - https://attack.mitre.org
